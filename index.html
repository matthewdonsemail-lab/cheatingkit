Reverse engineer anything.

cheatingkit is a small service for taking a thing apart, changing its shape, and running it somewhere else. Plain words, no jargon wall.

What it is

Most tools make the simple part complicated. This one does the opposite. You bring the thing — a game, a community, a system — and the kit gives you the pieces, what each piece does, and what it can become somewhere else.

01

Start with the thing

Point at the game, the community, the system. The kit works on what you already have.

02

Say it plainly

Hard ideas get short sentences. If a sentence needs a glossary, it gets rewritten.

03

Keep it runnable

Every answer ends as something you can take somewhere else, not a note you archive.

What you can do

01

Take a community apart

See how a game or a community is put together, piece by piece, including the parts nobody wrote down.

02

Change the modality

Move a game into a different form without losing what made it work in the first place.

03

Carry it to a custom OS

Bring the result onto the system you actually run, not the one the docs assume you run.

04

Rewrite the complicated bit

Feed it the dense version. Get the short version back.

Get started

The site is one HTML file. No build step, no dependencies. Clone it and open it.

$ git clone <your-fork-url> cheatingkit $ cd cheatingkit $ open index.html

# <your-fork-url> is a placeholder until the repo has a remote.
