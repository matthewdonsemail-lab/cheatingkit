# Local context and search

CheatingKit uses local Claude Code, Codex, and Hermes transcripts to provide source-linked context for a new request. The shared pipeline imports durable records, retrieves related user messages, attaches nearby later messages and observed warning responses, then returns a bounded context pack. The user's prompt is left intact.

## Import and index

`ck ingest` reads complete new JSONL rows or Hermes message IDs into SQLite. Source cursors and unique message IDs make repeated imports safe. `ck index` imports new rows and updates four-message search windows. Changed windows receive MiniLM embeddings; SQLite FTS5 supplies keyword matches. The index can be rebuilt from imported messages.

`ck label` separately assigns topic labels to messages and records the lead-up to observed cyber warning responses. These observations are drawn from the response text and source order. They are evidence about a prior session, not a prediction that a new prompt will receive the same response.

## Per-message recall

At a prompt boundary, CheatingKit imports new records from the current transcript or Hermes store and searches earlier user messages across the three harnesses. Keyword overlap provides a local fallback when the semantic index is absent. When the index is available, MiniLM and FTS5 contribute candidate windows. Known workspace paths keep results within the current workspace; records without a workspace path can still appear. The context pack contains related user messages, nearby later user messages, nearby assistant responses, and observed warning responses. Every excerpt includes its harness, session, and message ID.

Later user messages are shown as later evidence, rather than silently replacing the earlier request. The current prompt remains authoritative. Results are limited to 4,500 characters by default; no relevant match returns no injected context.

## Harness delivery

Claude Code and Codex use `UserPromptSubmit` command hooks. Hermes uses a native `pre_llm_call` plugin. All three invoke the same `ck hook` command and database. `ck context --prompt "..."` previews that output; `ck mcp` exposes the same context builder through the `task_context` MCP tool. Install or remove the adapters with `ck hooks install` and `ck hooks remove`.

## Current scope

The current corpus is indexed with MiniLM and keyword search. Topic labels come from MiniLM. Structured goal extraction with GLiNER and a separately trained refusal likelihood model are later extensions; they do not run in this release. The context pack therefore reports observed responses and source-linked messages without inventing a hidden goal or a numeric refusal probability.
