# Getting started

Install the published `ck` command from cheatingkit.com, then index your existing local conversations. You do not need a repository checkout or a development server.

## Install CheatingKit

First, [install Bun](https://bun.sh/docs/installation). Run the installer for your shell:

**macOS or Linux**

```sh
curl -fsSL https://cheatingkit.com/install.sh | sh
```

**Windows PowerShell**

```powershell
irm https://cheatingkit.com/install.ps1 | iex
```

The version controlled website installers look up npm's `latest` release, install that exact published version, and verify `ck --version`. For nightlies or a specific version, see [Releases and installation](/docs/releases).

## Set up local sessions

```sh
ck setup
```

Setup detects local Claude Code, Codex, and Hermes session sources. It creates `~/.cheatingkit/config.yaml` and a local SQLite database, then asks whether to import existing sessions. If local models are enabled, it can also label imported messages. Your index remains on your machine.

## Inspect your history

```sh
ck sessions
ck timeline
ck leadups
```

`ck sessions` lists imported sessions. `ck timeline` shows recorded events and model changes. `ck leadups` shows the messages before recorded warnings. After you have labeled messages with `ck label`, use `ck areas` for a topic summary. Run `ck ingest` when you have new conversations to import.

## Keep ck current

```sh
ck updates
ck update --apply
```

You can rerun the website installer to install npm's current stable release. Updates keep your local configuration and database in place. [Releases and installation](/docs/releases) explains stable, nightly, and pinned versions.
