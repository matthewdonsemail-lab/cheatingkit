# Getting started

This page separates the working repository commands from the complete system described elsewhere in the docs.

## Run the site

From the repository root, run `npm install` and `npm run dev`, then open `http://127.0.0.1:5173/docs`. Run `npm run build` to create the static bundle.

## CLI commands today

The current Bun CLI can detect Claude Code, Codex, and Hermes, create a local SQLite database, import sessions, show a timeline, and label message topics with MiniLM. Its development entry point is `bun run cli`. For example, `bun run cli setup`, `bun run cli ingest`, `bun run cli sessions`, and `bun run cli label`.

## System specification

The documentation defines the local search, GLiNER extraction, cited context pack, and harness integrations against the contracts in [Local context and search](/docs/models/context-pipeline). Use the development commands above with this checkout.

The `ck` package staging, CI release workflows, and website installer scripts are in the repository. See [Releases and installation](/docs/releases) for the stable and nightly flow. Publication requires npm access and the repository's `NPM_TOKEN` secret; installers select a track only after npm has a package on it.

The capability directories and naming rules are documented in [Code structure](/docs/code-structure).
