# Claude Code hooks

Claude Code provides `SessionStart`, `UserPromptSubmit`, `PreToolUse`, and `PostToolUse` hook points through its settings. CheatingKit uses those events to keep its index current and to supply cited task context at the prompt boundary.

## Event flow

A session or tool event signals an incremental transcript import. The importer reads Claude Code's JSONL and commits complete records using its per-file cursor. A prompt event asks the local context service for earlier user goals and corrections in the same workspace. The service returns a bounded context pack with source message IDs and leaves the user's prompt intact.

## Installation

`ck setup` or `ck hooks install` adds CheatingKit's `UserPromptSubmit` entry to `~/.claude/settings.json` while preserving other hooks. `ck hooks remove` removes its own entry. The hook returns `additionalContext` beside the unchanged prompt and does not enforce the [per-message gate](/docs/gate); enforcement requires the local proxy. [Getting started](/docs/getting-started) shows the installed commands.
